# Pelipäivä — 5-point test spec

1. **User Journey:** Parent pastes three association URLs, sees Saturday collisions, opens parking + weather + sport stats drawers.
2. **Reason it exists:** One car, two kids, three sports — the hub must stitch satellites without breaking contracts.
3. **What it tests:** `MatchdayContextContract`, `ParkingRiskContract`, `SportStatsContract`, `WeatherForecastContract`, neighbor visit.
4. **When it succeeds:** All `needs[]` houses still publish AGENTS.md + provided interfaces; conflict engine flags overlap.
5. **When it should fail:** Satellite drops `deepLinkUrl`; SupportedSport loses a sport; neighbor repo 404.
